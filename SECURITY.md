# Security Policy

[English](#english) | [한국어](#korean)

<a id="english"></a>

## English

RustOS is experimental and is not yet intended for production security
boundaries.

Report suspected vulnerabilities privately when possible. If private reporting
is unavailable, open an issue with only the minimum safe description and avoid
posting exploit details, secrets, or host-specific sensitive data.

Useful security reports include:

- Affected component or path.
- Reproduction steps.
- Expected and observed behavior.
- Impact assessment.
- Host, QEMU, firmware, and Rust toolchain versions when relevant.

<a id="korean"></a>

## 한국어

RustOS는 실험적 프로젝트이며 아직 production security boundary로 사용할
단계가 아닙니다.

취약점으로 의심되는 내용은 가능하면 비공개로 제보합니다. 비공개 제보 경로가
없다면 exploit detail, secret, host-specific 민감 정보를 제외하고 최소한의
안전한 설명만 issue로 남깁니다.

좋은 보안 제보에는 다음이 포함됩니다.

- 영향을 받는 component 또는 path
- 재현 절차
- 기대 동작과 실제 동작
- 영향도
- 관련 있는 host, QEMU, firmware, Rust toolchain version
