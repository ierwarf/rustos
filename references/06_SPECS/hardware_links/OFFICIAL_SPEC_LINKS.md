# 공식 명세 링크

- UEFI specifications: https://uefi.org/specifications
- ACPI specifications: https://uefi.org/specifications
- Intel software developer manuals: https://www.intel.com/content/www/us/en/developer/articles/technical/intel-sdm.html
- AMD architecture manuals: https://www.amd.com/en/search/documentation/hub.html
- Arm architecture and ABI: https://developer.arm.com/Architectures and https://github.com/ARM-software/abi-aa
- RISC-V ISA manual: https://github.com/riscv/riscv-isa-manual
- VirtIO: https://github.com/oasis-tcs/virtio-spec
- Devicetree: https://github.com/devicetree-org/devicetree-specification
- PCI-SIG: https://pcisig.com/specifications
- USB-IF documents: https://www.usb.org/documents
- NVM Express specifications: https://nvmexpress.org/specifications/
- TCG TPM library: https://trustedcomputinggroup.org/resource/tpm-library-specification/
- DWARF: https://dwarfstd.org/
- ELF gABI: https://www.sco.com/developers/gabi/latest/contents.html
- x86-64 psABI: https://gitlab.com/x86-psABIs/x86-64-ABI
- The Open Group Base Specifications: https://pubs.opengroup.org/onlinepubs/9799919799/
